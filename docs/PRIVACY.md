# Privacy

Meralvo is designed as a fully offline personal planning application.

- Financial data stays on the device in app-private storage.
- The app has no account or authentication.
- The app has no analytics, tracking, or advertising SDK.
- The app has no application server or cloud database.
- There is no automatic cloud synchronization.
- Backup export is user-controlled; an exported file may be shared or stored wherever the user chooses.
- Import replaces local app data only after the user chooses a backup and confirms the operation.
- Uninstalling the app removes its app-private data unless the user has separately retained an exported backup.

The Android application does not request Internet permission for its offline core.
